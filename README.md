# Leadflow

Квалификация входящих заявок из Битрикс24. Сервис выделяет потребность клиента,
бюджет, количество пользователей и сроки, показывает подтверждающие цитаты
и помогает выбрать заявки для проверки.

## Возможности

- Автоматический анализ новых лидов и ручной анализ по ID.
- Выбор поля Битрикс24, из которого загружается текст заявки.
- Результаты с фактами, цитатами, приоритетом и вопросами для клиента.
- История с поиском по ID лида и фильтрами по статусу и приоритету.
- Запись выбранных значений в Битрикс24 после подтверждения сотрудником.
- Роли администратора и менеджера, приглашения и отключение пользователей.

Менеджер видит свои результаты. Администратор видит результаты всех сотрудников,
управляет доступом и настраивает автообработку.

## Как пользоваться

1. Войдите с логином и паролем. Для первого входа установите пароль по приглашению.
2. В истории выберите заявку или нажмите **Загрузить лид** и укажите его ID.
3. Проверьте извлечённые факты. Нажмите на цитату, чтобы увидеть её в исходном тексте.
4. Уточните недостающие данные у клиента.
5. Выберите поля для записи, проверьте изменения и подтвердите сохранение в Битрикс24.

Для автоматической обработки администратор выбирает источник текста, получателя
результатов и интервал проверки в разделе **Автообработка**.
Результаты появятся в истории. Запись в Битрикс24 требует отдельного подтверждения.

## Установка и сопровождение

[Настройка сервиса, подключение Битрикс24 и запуск проверок](docs/deployment.md).

При установке создаётся пустая база. Пользователи, подключения и заявки
настраиваются для вашей организации. Данные для автоматических проверок
находятся только в тестах и не загружаются в приложение.
